Q: @Pharos Docs MCP Is there an official list of launchpad or DEX factory contracts on Pharos mainnet that I could index, like FaroSwap or a token launchpad?

Matched Pharos Docs MCP, reply below:

Where to look instead

The docs don't cover this, so you'll need to go outside them:

Pharos Block Explorer — https://www.pharosscan.xyz — search for verified contracts named "Factory", "Router", "Launchpad", or look for the well-known FaroSwap / launchpad deployer addresses if the community has published them.
Protocol's own docs / GitHub / Discord — each DeFi project (FaroSwap, any launchpad) publishes its own deployed addresses.
Chainlist / DeFiLlama / community repos — often maintain curated address lists for EVM chains.
Trace the deployer — if you know one pool/token from the launchpad, look at its transaction history on the explorer to find the factory that created it.

This is outside the scope of what the Pharos docs cover, so I can't give you a definitive address list from this source.
